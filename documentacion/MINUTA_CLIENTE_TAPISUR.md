## Contexto relevado

Tapisur es un emprendimiento familiar dedicado a la fabricación de sillones, muebles a medida, trabajos de tapicería, retapizados, reparaciones y restauraciones.

Actualmente el negocio trabaja principalmente con consultas por WhatsApp y fabricación a pedido. También cuenta con presencia digital y utiliza Tienda Nube, pero se detectaron dificultades para administrar esa herramienta y para centralizar la información comercial.

La información del negocio se encuentra distribuida entre conversaciones, anotaciones manuales y herramientas no integradas. Esto dificulta el seguimiento de consultas, clientes, ventas y trabajos realizados.

## Necesidad detectada

El cliente necesita una solución simple que ayude a ordenar la gestión comercial y administrativa sin reemplazar de forma inmediata sus canales actuales.

La prioridad es mantener WhatsApp como canal principal de contacto y sumar una plataforma web que permita mostrar productos, servicios y administrar información interna desde un panel sencillo.

## Decisiones principales

- El sistema será una aplicación web.
- El enfoque inicial será mobile-first, priorizando el uso desde celular.
- WhatsApp seguirá siendo el canal principal de contacto comercial.
- El sistema no reemplazará inicialmente a Tienda Nube.
- El catálogo podrá mostrar productos sin stock obligatorio y sin precio fijo obligatorio.
- Los servicios se considerarán sujetos a presupuesto personalizado.
- Se implementará un panel administrador para gestionar productos, servicios, contenido, clientes y ventas simples.
- Se utilizará GitHub para versionado y Trello para organización del trabajo.

## Alcance MVP validado

El MVP inicial contempla:

- Sitio web institucional y comercial.
- Catálogo público de productos.
- Sección pública de servicios.
- Botones de consulta por WhatsApp.
- Login de administrador.
- ABM de productos.
- ABM de servicios.
- Administración básica de contenido.
- Registro interno de clientes.
- Clasificación de clientes como minoristas, mayoristas o revendedores.
- Registro simple de ventas.
- Historial simple de ventas.

## Fuera del alcance inicial

Queda fuera del MVP:

- Facturación electrónica.
- Pasarela de pagos.
- Carrito de compras.
- Checkout online.
- Gestión avanzada de stock.
- Logística avanzada.
- Automatización completa del proceso productivo.
- Integración técnica directa con Tienda Nube.

## Pendientes a validar en próximas reuniones

- Confirmar si las ventas simples entran en la primera entrega o si quedan para una segunda etapa.
- Confirmar si se mostrará precio orientativo o solo consulta por presupuesto.
- Confirmar datos mínimos obligatorios de cliente.
- Confirmar si habrá más de un vendedor interno.
- Confirmar si materiales, colores y medidas serán catálogos administrables o campos de texto.
- Confirmar si se requiere algún reporte específico para cierres semanales o mensuales.
